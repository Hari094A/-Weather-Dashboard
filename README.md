# 🌦 Weather Dashboard

A modern and responsive Weather Dashboard built using **HTML5, CSS3, and JavaScript**. This application fetches real-time weather data from the **OpenWeather API** and displays current weather information with a clean glassmorphism user interface.

---

## 🚀 Features

- 🔍 Search weather by city name
- 🌡 Real-time temperature
- ☁ Weather description & icon
- 💧 Humidity
- 💨 Wind Speed
- 🌡 Feels Like Temperature
- 📈 Atmospheric Pressure
- 👀 Visibility
- 📅 Live Date & Time
- 📱 Fully Responsive Design
- 🎨 Modern Glassmorphism UI
- ⚡ Fast and Lightweight
- ❌ Error handling for invalid city names

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeather API
- Font Awesome
- Google Fonts (Poppins)
